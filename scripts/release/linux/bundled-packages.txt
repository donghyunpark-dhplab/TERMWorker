# Ubuntu 22.04 packages whose files the AppImage may carry, each checked for its licence.
# build.sh fails when it bundles a package that is not listed here: check the licence of
# the library itself in /usr/share/doc/<package>/copyright (Debian's "Files: *" line is the
# source package's licence, which can be GPL while the library is LGPL), then add it.
# Never add a package whose library is GPL-only. Reviewed 2026-11-23: all LGPL or
# permissive. Notes on the ones whose copyright file looks GPL at first sight:
#   libblkid1, libmount1  util-linux: the libraries are LGPL-2.1+
#   libcolord2            colord: lib/colord is LGPL-2.1+
#   libkeyutils1          keyutils: the library is LGPL-2.1+
#   libidn2-0             LGPL-3+ or GPL-2+
#   libdw1, libelf1       elfutils: LGPL-3+ or GPL-2+
#   libffi8, libkrb5-3 and friends: MIT-style; GPL is mentioned only for build files
# Left out on purpose (build.sh removes them): libjbig0 (GPL-2+) and libtiff5 with GTK's
# TIFF image loader, which is the only thing that needs libjbig.
